# blitzbrief-cyberpunk-chat

## (W.I.P.) Website is still a Work In Progress;

Command Guide:
- **Left Click** on a contact selects it.
- **Right Click** on a contact adds 'unread' mark.
- **Message Input + (Enter)** can send a new message to the history.
- **Alt + P** toggles scrollbar on the full site, to check any elements out of bounds.
